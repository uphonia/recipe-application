# Recipe Store

A place where you can create and store your recipes.<br/> 

### Tech Stack
* React
* Typescript
* Python
* Django
* Docker

### Commands
* Build and run: `docker-compose -f docker-compose.yml -f docker-compose.dev.yml up -d --build`
* Spin down: `docker compose -f docker-compose.yml -f docker-compose.dev.yml down`
* Spin down and remove: `docker compose -f docker-compose.yml -f docker-compose.dev.yml down -v`

### Note
This is a continuous work-in-progress, prioritizing functionality and learnings over styling :)
